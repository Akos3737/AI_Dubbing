# 🎬 Video Translation & Dubbing Pipeline

이 프로젝트는 비디오를 한국어로 번역하고, TTS로 더빙하여 새로운 비디오를 생성하는 파이프라인입니다.

---

## 📁 사전 준비

1. `main_project` 폴더에 **`sample_voice.wav`** 파일을 넣어주세요.  
   (이 파일은 TTS 목소리의 기준이 됩니다.)
2. 변환하고 싶은 비디오 파일을 `main_project` 폴더에 추가합니다.  
   예제 파일은 `sample_video.mp4`입니다.

---

## 🚀 실행 방법

1. **VSCode**에서 `pj_gui.py` 파일을 실행합니다.
2. GUI 창에서 **[찾아보기]** 버튼을 눌러 원하는 비디오를 선택하세요.
3. **[실행]** 버튼을 누르면 전체 변환 작업이 자동으로 진행됩니다.

---

## 📂 결과물

- 작업이 완료되면 `outputs` 폴더 내에 **입력 비디오 이름과 동일한 이름의 폴더**가 생성됩니다.
- 그 폴더 안에 **합성된 비디오 (`output_dubbed.mp4`)**가 저장됩니다.
